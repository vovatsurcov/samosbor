# Шаблон каталога ассета

Копия этого каталога — стартовая структура для одного ассета. Создавать вручную не нужно:

```bash
art/_scripts/new-asset.sh WPN-ENG-01
```

Скрипт определяет категорию по префиксу идентификатора, создаёт каталог в нужном месте и кладёт заготовку `meta/asset.meta.json`.

Подкаталоги, бессмысленные для конкретного ассета, можно удалить: у предмета без анимаций не нужен `animations/`, у неподвижного реквизита — `rig/`.
