# Самосбор: Смена 556

Браузерный прототип системной action RPG в мире бесконечной Гигахрущёвки. Мир живёт в непрерывном времени: герой исследует этажи, сражается, взаимодействует с инфраструктурой, собирает экипировку, развивает собственный архетип и пытается пережить последствия Самосбора.

## Что находится в репозитории

- игровая симуляция, отделённая от интерфейса;
- перемещение и бой в реальном времени;
- зрение, слух, память, тревога и отступление противников;
- полный цикл Самосбора с предвестниками, сиреной, активной фазой и последствиями;
- оружие ближней, средней и дальней дистанции;
- экипировка, вес, износ, расходники, заражение, стресс и травмы;
- 125 узлов развития, 18 автоматических протоколов и 15 совмещённых допусков;
- уровни 1–50, опыт от боёв, заданий и исследования;
- физические геномные популяции, миграция и потери от действий героя;
- поддержка клавиатуры/мыши, касаний, геймпада и телевизионного пульта;
- HUD, инвентарь, персонаж, развитие и экран диагностики управления;
- локальное сохранение и воспроизводимая симуляция;
- тесты ядра игрового движка;
- полный дизайн-документ в `docs/GAME_DESIGN.md`;
- система развития в `docs/CHARACTER_PROGRESSION.md`;
- интерфейс автокаста и развития в `docs/PROGRESSION_UI.md`;
- архитектура базовых 50 этажей в `docs/LEVEL_ARCHITECTURE_50_FLOORS.md`.

## Текущий статус

Проект перешёл к этапу **5 / World Foundation**. Уже работают связанные этажи, физические геномные популяции, уровни 1–50, опыт, отдельные бюджеты развития и автоматические боевые протоколы. Следующий крупный блок — вертикальный граф этажей 556–507, просторные районные карты, обучающая цепочка 556–555 и вход в многоэтажный Город 550.

Подробное расхождение между реализованным кодом и проектным состоянием зафиксировано в `docs/STATUS.md`.

## Запуск локально

Требования:

- Node.js 22.13 или новее;
- npm 10 или новее;
- Linux, macOS или Windows с WSL.

```bash
npm ci
npm run dev
```

Для запуска в локальной сети:

```bash
npm run lan
```

После запуска откройте адрес, который выведет Vite.

## Проверки

Проверка игрового ядра не требует сборки интерфейса:

```bash
npm run test:engine
```

Полная проверка:

```bash
npm test
npm run lint
```

## Основные файлы

- `app/game-engine.ts` — состояние мира, симуляция, ИИ, бой, предметы и сохранения;
- `app/game-prototype.tsx` — игровой экран и интерфейс;
- `app/game-items.ts` — предметы и экипировка;
- `app/game-skills.ts` — ветви развития, навыки и синергии;
- `app/game-samosbor.ts` — фазы Самосбора, профили этажей и расчёт экспозиции;
- `app/globals.css` — визуальная система и адаптивный HUD;
- `tests/game-engine.test.mjs` — тесты механик ядра;
- `docs/SAMOSBOR_EVENT.md` — цикл события, расписание мира, защита контура и цена прямого контакта;
- `art/` — исходники визуальных ассетов: реестр, правила именования и пайплайн в `art/_docs/`;
- `docs/GAME_DESIGN.md` — полный игровой дизайн;
- `docs/CHARACTER_PROGRESSION.md` — уровни, опыт, специализации, гибриды и развитие после 50 уровня;
- `docs/PROGRESSION_UI.md` — интерфейс развития, архетипов и автоматических протоколов;
- `docs/LEVEL_ARCHITECTURE_50_FLOORS.md` — вертикальный мир, города, поселения, Самосбор, слизь, ликвидаторы и тайные маршруты;
- `docs/ROADMAP.md` — план движения к вертикальному срезу уровня Diablo II по полноте цикла.

## Архитектурный принцип

Игровая логика не зависит от React и частоты кадров. Интерфейс отображает сериализуемое состояние и отправляет команды в движок. Это позволяет позднее заменить SVG-рендер на Canvas/WebGL, не переписывая правила мира, сохранения и тесты.
