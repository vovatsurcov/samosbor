# Самосбор: Смена 556

Браузерный прототип системной action RPG в мире бесконечной Гигахрущёвки. Мир живёт в непрерывном времени: герой исследует этажи, сражается, взаимодействует с инфраструктурой, собирает экипировку, развивает гибридный билд и пытается пережить последствия Самосбора.

## Что находится в репозитории

- игровая симуляция, отделённая от интерфейса;
- перемещение и бой в реальном времени;
- зрение, слух, память, тревога и отступление противников;
- оружие ближней, средней и дальней дистанции;
- экипировка, вес, износ, расходники, заражение, стресс и травмы;
- 125 узлов развития, 18 активных навыков и 15 совмещённых допусков;
- поддержка клавиатуры/мыши, касаний, геймпада и телевизионного пульта;
- HUD, инвентарь, персонаж, таланты и экран диагностики управления;
- локальное сохранение и воспроизводимая симуляция;
- тесты ядра игрового движка;
- полный дизайн-документ в `docs/GAME_DESIGN.md`.

## Текущий статус

Доступный исходный снимок соответствует этапу **3C**. Этап 4 подробно описан в дизайн-документе и является следующим крупным блоком разработки: связанные протяжённые этажи, геномные популяции, поселения, автономные боссы, рейды, восстановление деревень, квесты и серверный снимок общего мира.

Подробное расхождение между реализованным кодом и проектным состоянием зафиксировано в `docs/STATUS.md`.

## Запуск локально

Требования:

- Node.js 22.13 или новее;
- npm 10 или новее;
- Linux, macOS или Windows с WSL.

```bash
npm ci
npm run dev
```

Для запуска в локальной сети:

```bash
npm run lan
```

После запуска откройте адрес, который выведет Vite.

## Проверки

Проверка игрового ядра не требует сборки интерфейса:

```bash
npm run test:engine
```

Полная проверка:

```bash
npm test
npm run lint
```

## Основные файлы

- `app/game-engine.ts` — состояние мира, симуляция, ИИ, бой, предметы и сохранения;
- `app/game-prototype.tsx` — игровой экран и интерфейс;
- `app/game-items.ts` — предметы и экипировка;
- `app/game-skills.ts` — ветви развития, навыки и синергии;
- `app/globals.css` — визуальная система и адаптивный HUD;
- `tests/game-engine.test.mjs` — тесты механик ядра;
- `docs/GAME_DESIGN.md` — полный игровой дизайн;
- `docs/ROADMAP.md` — план движения к вертикальному срезу уровня Diablo II по полноте цикла.

## Архитектурный принцип

Игровая логика не зависит от React и частоты кадров. Интерфейс отображает сериализуемое состояние и отправляет команды в движок. Это позволяет позднее заменить SVG-рендер на Canvas/WebGL, не переписывая правила мира, сохранения и тесты.
