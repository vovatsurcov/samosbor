# Шесть боевых архетипов v2

Версия: 2.0  
Статус: реализовано. Этап A подтверждён владельцем проекта, этапы B и C выполнены. Построен на числовой модели `COMBAT_NUMERIC_MODEL_V2.md`; ни одна способность здесь не выражена в «+3% туда».

## 1. Технические идентификаторы

```text
power         силач          ближний бой
bulwark       танк           ближний бой
skirmisher    ловкач         ближний бой
marksman      стрелок        дальний бой
heavy_gunner  тяжёлый стрелок дальний бой
resonance     резонанс       дальний бой, аномальный
```

Изменения относительно старой системы:

- отдельной ветки скрытности больше нет: скрытность становится инструментом ловкача и стрелка, а не образом жизни;
- инженер выведен из боевых специализаций в отдельную систему профессий (`CLAUDE_VISUAL_COMBAT_WORKSTREAM_V2.md` §4) и в этом дереве не участвует;
- старые ветки `force`, `fire`, `stealth`, `bulwark`, `engineer`, `resonance` мигрируют по таблице §8.

«Пси-маг» из рабочего названия закрепляется как **резонанс**: это не магия, а работа с резонансом пространства, помехами и разрывом синхронизации. Слово «маг» в игровых текстах не появляется.

## 2. Ресурс специализации

Поверх общих ОЗ, стойки и дыхания каждый архетип получает **один** собственный ресурс. Ресурс всегда виден, всегда тратится осознанно и всегда имеет цену.

| Архетип | Ресурс | Набирается | Тратится |
| --- | --- | --- | --- |
| `power` | **Разгон** | движение к цели, попадания тяжёлыми | таран, слом стойки, добивание |
| `bulwark` | **Опора** | удержание блока, идеальные блоки | контратака, толчок, удержание прохода |
| `skirmisher` | **Темп** | смена позиции, уклонения, удары в спину | серия, заход за спину, добивание |
| `marksman` | **Прицел** | неподвижность, попадания в одну цель | точный выстрел, метка, разрыв дистанции |
| `heavy_gunner` | **Температура** | стрельба (растёт сама) | обратный ресурс: перегрев наказывает |
| `resonance` | **Резонанс** | попадания резонансным уроном, аномалии | контроль зоны, цепи, разрыв |

Температура — единственный ресурс-антагонист: она не тратится, а накапливается и требует управления. Это и есть характер тяжёлого стрелка.

Резонанс дополнительно повышает стресс и заражение героя — цена силы, уже существующая в игре.

## 3. Боевые цепочки

Ветка обязана менять поведение игрока, а не цифру DPS. Ниже — базовая цепочка каждого архетипа: это и есть проверка, что архетип состоялся.

### 3.1. `power` — силач

```text
разгон → таран → слом стойки → тяжёлый удар → добивание
```

| Способность | Механика |
| --- | --- |
| **Разгон** | 2 с непрерывного движения к цели дают ступень разгона (до 3). Каждая ступень: +12% урона по стойке и +0.15 к скорости |
| **Таран** | рывок на 4 клетки сквозь врагов; каждому задетому — тяжёлый урон по стойке, сбивание с ног при полном разгоне |
| **Слом стойки** | заряжаемая атака: 200 мс на ступень, до 3 ступеней; по пошатнувшейся цели гарантированно вызывает ошеломление |
| **Тяжёлый удар** | по ошеломлённой цели наносит урон в конусе за ней: враг используется как таран |
| **Добивание** | 2.2× урона, восстанавливает 25% стойки героя и половину разгона |

Цена: разгон обнуляется при остановке, блоке и уклонении. Силач не может играть от осторожности — он обязан двигаться вперёд.

### 3.2. `bulwark` — танк

```text
защищённое сближение → блок → идеальный блок → контратака → удержание прохода
```

| Способность | Механика |
| --- | --- |
| **Защищённое сближение** | движение с поднятым блоком без штрафа скорости на 3 с; дыхание тратится вдвое медленнее |
| **Идеальный блок** | окно 180 мс: урон 0, атакующему 1.5× в стойку, окно контратаки 900 мс |
| **Контратака** | внутри окна следующая атака считается тяжёлой и не стоит дыхания |
| **Толчок щитом** | отбрасывание на 2 клетки, прерывание подготовки, +опора |
| **Удержание прохода** | в узком месте (клетка с двумя стенами по бокам) блок держит дугу 360° и не ломается при нуле дыхания |

Цена: вне блока танк наносит меньше всех урона. Его сила — не выживание само по себе, а превращение чужих ошибок в свои окна.

### 3.3. `skirmisher` — ловкач

```text
рывок → контакт → серия → перепозиционирование → заход за спину → добивание
```

| Способность | Механика |
| --- | --- |
| **Рывок** | 2.2 клетки, 300 мс неуязвимости; сквозь противника — только с талантом |
| **Серия** | 3 быстрых удара; каждый следующий +15% урона, вся серия прерывается любым уроном |
| **Перепозиционирование** | смена стороны цели за 2 с даёт темп; на 3 темпах следующая атака бьёт как в спину независимо от угла |
| **Заход за спину** | короткий рывок в тыл цели; удар считается `unaware` (×1.35) |
| **Добивание** | по цели с ОЗ ниже 20% — мгновенное, дешёвое, восстанавливает темп |

Цена: ловкач не переживает прямой размен. Его стойка и ОЗ минимальны, вся защита — в идеальном уклонении и позиции.

### 3.4. `marksman` — стрелок

```text
разведка → метка → выбор цели → точный выстрел → разрыв дистанции
```

| Способность | Механика |
| --- | --- |
| **Разведка** | +2.5 к радиусу обзора и подсветка врагов за укрытием на 6 с |
| **Метка** | цель получает метку: +20% входящего урона от всех источников, видна сквозь стены |
| **Точный выстрел** | 700 мс прицеливания без движения; игнорирует укрытие и половину брони |
| **Первый выстрел** | по цели, не знающей о герое, — гарантированный крит |
| **Разрыв дистанции** | прыжок назад с выстрелом; замедляет ближайшего преследователя |

Цена: прицел набирается неподвижностью, а стрелок обязан двигаться, когда до него дошли. Прямой конфликт ресурса и выживания — это и есть игра стрелка.

### 3.5. `heavy_gunner` — тяжёлый стрелок

```text
занять позицию → развернуть оружие → раскрутка → подавление → перегрев → сброс температуры
```

| Способность | Механика |
| --- | --- |
| **Занять позицию** | 1 с установки: +30% урона, −70% скорости, стойка не ломается обычными атаками |
| **Развернуть оружие** | из походного положения в боевое; вне позиции урон снижен на 40% |
| **Раскрутка** | темп стрельбы растёт 4 с подряд: 240 мс между выстрелами → 120 мс; температура растёт быстрее |
| **Подавление** | враги в конусе теряют дыхание и точность, прекращают сближение; не наносит урона |
| **Перегрев** | при 100 температуры оружие блокируется на 3 с и наносит герою термический урон |
| **Сброс температуры** | −60 температуры, 1.5 с уязвимости; сбрасывает раскрутку |

Цена: полностью противоположна ловкачу. Тяжёлый стрелок силён только там, где успел встать, и обязан заранее выбирать место боя.

### 3.6. `resonance` — резонанс

```text
метка резонанса → искажение зоны → цепь → разрыв синхронизации → цена
```

| Способность | Механика |
| --- | --- |
| **Метка резонанса** | накапливает стеки на цели; резонансный урон почти игнорирует броню |
| **Искажение зоны** | область 3 клетки: замедление, потеря ориентации, ломается линия видимости врагов |
| **Цепь** | эффект переходит между целями с меткой: до 4 переходов, каждый слабее на 20% |
| **Разрыв синхронизации** | цель с 4 стеками теряет ход: прерывание, −50% стойки, принудительное перемещение |
| **Обратная тень** | герой на 2 с существует «не полностью»: неуязвим, не может атаковать, +15 заражения |

Цена: каждая крупная способность добавляет стресс и заражение. Резонансная сборка сильна против брони и групп, но сама себя разрушает — это единственный архетип, ограниченный не откатами, а состоянием героя.

## 4. Три режима управления

Один и тот же билд играется тремя способами. Режим переключается вне боя и виден в HUD.

### 4.1. Ручной

Полный контроль. Все способности на панели, автоматика отключена.

**Эффективность: 100%.** Это верхняя планка, относительно которой считаются остальные режимы.

### 4.2. Директива

Игрок задаёт правила, а не нажимает кнопки. Правило — тройка `условие → действие → приоритет`; список проверяется сверху вниз, срабатывает первое подходящее.

```text
если ОЗ < 30%                → защитная способность
если стойка цели сломана     → тяжёлый удар
если целей вокруг ≥ 3        → удар по площади
если цель без метки          → метка
если температура > 80        → сброс температуры
если дыхание < 25            → отступить
```

Доступные условия первого набора:

```text
hp_below            доля ОЗ героя
breath_below        доля дыхания
resource_above      доля ресурса специализации
target_staggered    цель ошеломлена
target_shaken       стойка цели ниже 25%
target_unmarked     на цели нет метки
enemies_within      число врагов в радиусе
target_hp_below     доля ОЗ цели
incoming_heavy      противник начал тяжёлую атаку
in_position         герой в устойчивой позиции
```

**Эффективность: 85–92%** от ручного при хорошо составленном списке. Директива не знает будущего: она не может придержать способность под окно, которое ещё не наступило.

### 4.3. Автоконтур

Полностью самостоятельная ротация. Игрок задаёт только характер: агрессивный, экономный, оборонительный. Герой сам сближается, отступает, блокирует, лечится и добивает.

**Эффективность: 70–80%** и отдельная цена:

- расход расходников выше на 25%: автоматика не экономит;
- износ экипировки выше на 20%;
- добивания используются только при полной безопасности, поэтому часть урона теряется;
- автоконтур не входит в войд-зоны и не начинает бой с боссом без команды.

Автоконтур — не «режим для ленивых», а осознанный обмен: игрок платит ресурсами за возможность не вести бой руками. На нём можно пройти игру, но нельзя пройти её оптимально.

### 4.4. Общее правило

Ни один режим не отключает опасность. Во всех трёх режимах активная фаза Самосбора, ошеломление и прямой контакт с боссом требуют решений игрока: автоматика не умеет искать гермодверь.

## 5. Три примера сборки

| Сборка | Ветки | Как играется |
| --- | --- | --- |
| **Пролом** | `power` 14 / `bulwark` 6 | разгон и таран внутрь группы, слом стойки, добивание; блок только чтобы пережить ответ |
| **Тень коридора** | `skirmisher` 12 / `marksman` 8 | метка с дистанции, заход за спину, серия, разрыв дистанции, повтор |
| **Глушитель** | `resonance` 12 / `heavy_gunner` 8 | искажение зоны, метки, подавление из позиции, цепь по замедленной группе |

Каждая сборка обязана иметь ответ на три вопроса: как сближаться, как переживать давление, как ломать бронированную цель. Сборка без ответа на любой из них считается непроходной и требует правки дерева, а не героизма игрока.

## 6. Ранняя, средняя и поздняя игра

| Этап | Уровни | Что должно быть у любого архетипа |
| --- | --- | --- |
| Ранняя | 1–10 | базовая цепочка целиком: сближение, основное действие, выход |
| Средняя | 11–30 | ресурс специализации, два усиления цепочки, ответ на броню |
| Поздняя | 31–50 | окно, в котором архетип играет иначе: перегрев, обратная тень, удержание прохода |

Ранние таланты обязаны давать работающий билд: к 10-му уровню игрок уже играет своим архетипом, а не «копит на интересное».

## 7. Что удаляется из старой системы

- ветка `stealth` как боевая специализация;
- ветка `engineer` как боевая специализация;
- таланты вида «+N% к урону» без изменения поведения;
- узлы, дублирующие друг друга в разных ветках;
- боевые директивы `adaptive` / `mobileFire` / `splashGuard` в текущем виде — их заменяет система директив §4.2.

Рембот и крафт не удаляются, а ждут системы профессий: до отдельного решения владельца проекта они не привязываются ни к одному из шести архетипов.

## 8. Миграция сохранений

| Старая ветка | Новый архетип | Правило переноса |
| --- | --- | --- |
| `force` | `power` | очки переносятся один к одному |
| `bulwark` | `bulwark` | один к одному |
| `fire` | `marksman` | один к одному |
| `resonance` | `resonance` | один к одному |
| `stealth` | `skirmisher` | один к одному |
| `engineer` | — | очки возвращаются игроку как нераспределённые |

Новый архетип `heavy_gunner` не имеет предшественника: его очки игрок распределяет сам.

Полоса здоровья переносится долей: `ОЗ_новое = round(ОЗ_max_новое × доля_старого)` — функция `migrateHpShare` из `app/game-combat-model.ts`.

## 9. Состояние реализации

Владелец проекта подтвердил этап A и снял требование промежуточных согласований, поэтому этапы B и C выполнены подряд.

| Архетип | Ресурс в движке | Ключевые действия |
| --- | --- | --- |
| `power` | разгон от сближения | тяжёлый удар, добивание |
| `marksman` | прицел от неподвижности | метка, разведка |
| `bulwark` | опора от удержания блока | блок, идеальный блок, толчок щитом |
| `skirmisher` | темп от смены позиции | серия, заход за спину |
| `heavy_gunner` | температура растёт сама | позиция, раскрутка, подавление, сброс |
| `resonance` | стеки резонанса на цели | цепь, разрыв синхронизации, обратная тень |

Интерфейс подключён: полосы стойки и дыхания в карточке героя, кнопки тяжёлого удара (`Z`), блока (`V`, удержание), уклонения (`Shift`) и добивания (`B`), панель архетипа с полосой ресурса, двумя действиями (`G`, `H`), переключателем архетипа и режима управления (`M`).

Не реализовано и остаётся следующим шагом:

- перенос дерева из 125 узлов на шесть архетипов;
- редактор правил режима «Директива» в интерфейсе;
- заряжаемый удар силача и таран как отдельные действия;
- удержание прохода танка и первый выстрел стрелка.
