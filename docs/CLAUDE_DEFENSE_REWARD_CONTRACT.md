# Контракт Claude: награды за оборону

Версия: 0.1

## Задача

Claude отвечает за определение предметов отличного качества, выдаваемых за успешную оборону городов и малых поселений.

Мировой движок создаёт запись:

```ts
{
  quality: "excellent",
  poolId: "claude-defense-<settlement>",
  selectionAuthority: "claude",
  itemId: null
}
```

Пока Claude не добавил утверждённое определение, движок не подменяет награду случайным существующим предметом.

## Требования к предмету

Предмет должен:

- соответствовать уровню героя и сложности обороны;
- иметь отличное состояние;
- быть заметно сильнее обычной добычи региона;
- поддерживать несколько билдов или выбираться из нескольких вариантов;
- отражать специализацию города или поселения;
- не быть обязательным для прохождения;
- не обесценивать легендарные предметы;
- использовать существующую систему качества, модификаторов и экипировки.

## Город 545

Рекомендуемая тема пула:

- производственная броня;
- оружие ликвидаторов;
- инженерные устройства;
- герметическое снаряжение;
- модуль для защиты города.

Предмет должен визуально связывать верхний караванный и нижний промышленный ярусы Города 545.

## Малые поселения

Награда должна отражать местную специализацию:

- водяное поселение даёт фильтры, защиту или гидравлическое оружие;
- караванное поселение даёт грузовое, мобильное или навигационное снаряжение;
- медицинское поселение даёт защиту и восстановление;
- аномальное поселение даёт рискованные резонансные свойства.

## Интеграция

Claude добавляет:

1. определения предметов;
2. визуальные модели и иконки;
3. параметры качества;
4. допустимые уровни;
5. правила выбора из пула;
6. тесты совместимости с инвентарём;
7. миграцию незавершённых наградных контрактов.

До этого момента `itemId` остаётся `null`, а право на награду сохраняется в состоянии мира.
